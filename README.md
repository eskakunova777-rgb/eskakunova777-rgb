# Evgenia Skakunova · Vibe Coder & Automation

Собираю рабочие системы на ИИ для экспертов и небольшого бизнеса: автоматизацию заявок, ботов, лендинги с оплатой, контент-конвейеры и внутренние инструменты. 20 лет в международных финансах (MBA, Лондон), последние два года в ИИ, вайбкодинге и автоматизации.

**Как работаю:** бриф → фиксированная цена → короткие этапы с видеодемо → сдача с инструкцией и поддержкой. Общение перепиской и записями экрана.

## Что делаю

- **Автоматизация заявок:** формы, сайт, Telegram → таблица или CRM → уведомления и автоответы (n8n, Make, ChatPlace)
- **Боты с ИИ:** ответы по базе знаний, сбор заявок, выдача файлов по кодовому слову
- **Лендинги с оплатой:** текст, адаптивная страница, форма, приём оплаты, публикация на сервере
- **Контент-системы:** сбор идей, генерация, проверка и автопубликация
- **Внутренние инструменты:** трекеры, калькуляторы, генераторы документов
